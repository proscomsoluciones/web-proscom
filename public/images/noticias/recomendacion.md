# 📸 Recomendaciones para Imágenes de Noticias

Para mantener la calidad visual de **Proscom** y asegurar un rendimiento óptimo (SEO), sigue estas directrices al subir imágenes a esta carpeta:

### 📐 Dimensiones y Formato
*   **Dimensiones Idóneas**: 1200 x 675 píxeles (Relación de aspecto 16:9).
*   **Ancho Mínimo**: 1000 píxeles.
*   **Ancho Máximo**: 1600 píxeles.
*   **Formato Preferido**: **.webp** (Es el más rápido para Google).
*   **Alternativa**: .jpg comprimido. *Evita .png para fotografías.*

### 🚀 Optimización de Rendimiento
*   **Peso del archivo**: Máximo **200 KB** por imagen.
*   **Sugerencia**: Pasa tus fotos por [Squoosh.app](https://squoosh.app/) antes de guardarlas aquí.

### 🎨 Composición Visual
*   **Sujeto Centrado**: La web usa `object-cover` para adaptar la imagen a diferentes pantallas. Asegúrate de que lo más importante de la foto esté en el **centro**, para evitar que se corte en móviles o monitores muy anchos.
